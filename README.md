# Sistema de Cadastro de Alunos

Sistema web desenvolvido para realizar o cadastro e a visualização de alunos.

## Objetivo

O projeto foi desenvolvido como atividade prática da disciplina Material Design Framework.

O objetivo é aplicar conhecimentos de:

- Git;
- GitHub;
- HTML5;
- CSS3;
- JavaScript;
- Clean Code;
- trabalho colaborativo.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Funcionalidades

- Cadastro de alunos;
- exibição dos alunos cadastrados;
- validação dos campos;
- seleção de curso;
- interface responsiva;
- página de login.

## Como executar

1. Clone o repositório:

```bash
git clone https://github.com/joaopedropereiradelima/sistema-cadastro-alunos.git
```
